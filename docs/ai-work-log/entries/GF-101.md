## Task Summary & Goal

This task creates the core database foundation for the URL shortener: the `ShortUrl` JPA domain entity and its Spring Data `ShortUrlRepository` interface. It enables saving short links, querying active short links by code, and enforcing unique short codes at the database level. Analytics fields and caching are explicitly excluded from this task per iteration guidelines.

## Implementation Decisions & Rationale

* **Explicit Getters/Setters over Lombok `@Data`**: Avoided Lombok `@Data` on the JPA entity because mutable `equals()` and `hashCode()` implementations in JPA entities lead to subtle persistence set/map bugs. Implemented `equals()` based on entity ID identity.
* **Database-Level Unique Index**: Added `@Index(name = "idx_short_url_code", columnList = "code", unique = true)` on the `code` column to guarantee database-level uniqueness across concurrent requests.
* **Instant for Timestamps**: Used `java.time.Instant` for `createdAt` to ensure unambiguous UTC timestamp handling without timezone discrepancies.
* **Active-Only Lookup Method**: Added `findByCodeAndActiveTrue(String code)` to repository to cleanly filter out deactivated links during redirect lookup.
