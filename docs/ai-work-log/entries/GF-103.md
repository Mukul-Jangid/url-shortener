## Task Summary & Goal

Implement the public redirect endpoint `GET /{code}` that looks up an active `ShortUrl` record by code and returns `HTTP 302 Found` with `Location: <originalUrl>`. Unknown or inactive short codes return `HTTP 404 Not Found` (`UrlNotFoundException`).

## Implementation Decisions & Rationale

* **HTTP Status 302 Found**: Used temporary redirect (302) to ensure browsers revalidate on subsequent clicks, supporting future link deactivation and click analytics.
* **Service Method**: `getOriginalUrl(String code)` queries `ShortUrlRepository.findByCodeAndActiveTrue(code)` and throws `UrlNotFoundException` if missing or inactive.
* **Controller Isolation**: `RedirectController` handles the root-level `GET /{code}` route separately from management APIs under `/api/v1/urls`.
