## Task Summary & Goal

Implement the non-redirecting metadata lookup REST endpoint `GET /api/v1/urls/{code}` that returns short link details (`code`, `shortUrl`, `originalUrl`, `active`, `createdAt`) as JSON. Supports retrieving both active and deactivated links, returning `HTTP 200 OK` with `ShortUrlResponse` DTO or `HTTP 404 Not Found` if the code never existed.

## Implementation Decisions & Rationale

* **DTO Reuse**: Reuses `ShortUrlResponse` DTO to prevent exposing JPA entities directly.
* **Support for Deactivated Links**: Queries `ShortUrlRepository.findByCode(code)` (unfiltered by `active`) so metadata for deactivated links can still be inspected.
* **OpenAPI Documentation**: Annotated with `@Operation` and `@ApiResponses` (`200 OK`, `404 Not Found`).
