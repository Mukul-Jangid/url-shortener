## Task Summary & Goal

Establish centralized exception handling using Spring's `@RestControllerAdvice` mapping domain exceptions and validation errors to RFC 7807 `ProblemDetail` responses. Ensure no raw stack traces are returned to clients.

## Implementation Decisions & Rationale

* **Base Domain Exception (`UrlShortenerException`)**: Base runtime exception class for all domain-specific errors.
* **RFC 7807 `ProblemDetail` Responses**: Standardized JSON error response format using Spring 6 / Spring Boot 3 `ProblemDetail`.
* **Stable Problem Types**: Set `type` URIs (`urn:problem:url-not-found`, `urn:problem:invalid-url`, `urn:problem:validation-error`, `urn:problem:code-generation-failed`, `urn:problem:internal-error`).
* **Logging at Boundary**: Log unhandled server errors at `ERROR` level with stack trace; log client validation and 404 warnings at `WARN` level per logging guidelines.
