## Task Summary & Goal

Implement the deactivation REST endpoint `DELETE /api/v1/urls/{code}` that soft-deactivates an existing short URL record by setting `active = false`. Returns `HTTP 204 No Content` for successful or idempotent deactivation, and `HTTP 404 Not Found` if the code never existed.

## Implementation Decisions & Rationale

* **Soft Delete**: Hard delete is explicitly forbidden; sets `active = false` to preserve auditability and future click analytics history.
* **Idempotency**: Deactivating an already inactive link is idempotent and returns `204 No Content`.
* **Cross-Task Validation**: Verifies that after deactivation, `GET /{code}` redirect returns `404 Not Found` (`UrlNotFoundException`), while `GET /api/v1/urls/{code}` metadata lookup continues to return `200 OK` with `active: false`.
