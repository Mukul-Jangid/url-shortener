## Task Summary & Goal

Implement the `POST /api/v1/urls` REST endpoint that accepts a target long URL, validates its format, generates a random 7-character Base62 code with bounded collision retries (max 5 retries), persists the `ShortUrl` entity, and returns `HTTP 201 Created` with the short code and full short link.

## Implementation Decisions & Rationale

* **Code Length & Alphabet**: 7 characters using Base62 alphabet (`[a-z]`, `[A-Z]`, `[0-9]`) generated via `SecureRandom` ($3.52 \text{ trillion}$ theoretical capacity).
* **Bounded Collision Retries**: Maximum 5 retry attempts if a DB unique constraint collision occurs. Throws `CodeGenerationException` if retries fail.
* **Configurable Base URL**: Configured via Spring property `app.shortener.base-url` (defaults to `http://localhost:8080`).
* **DTO Separation**: Request payload (`CreateShortUrlRequest`) and response payload (`ShortUrlResponse`) decouple external REST contract from JPA domain entities.
* **URL Validation**: Validates non-blank, max length 2048 characters, absolute `http` or `https` scheme. Throws `InvalidUrlException` for malformed input.
