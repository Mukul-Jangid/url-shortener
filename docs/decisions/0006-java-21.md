# 0006: Use Java 21

- **Date**: 2026-09-26
- **Status**: Accepted — explicitly requested by the user
- **Task context**: SCAFFOLD-003
- **Supersedes**: The Java version in [0001](0001-tech-stack.md); other stack choices remain.

## Context

The scaffold selected Java 17 without documenting a version-specific requirement. The user's
environment uses Java 21, and the user wants the project to target Java 21 as well.

## Decision

Set Maven's `java.version` to 21 and require a full JDK 21 for development. Keep the existing
Spring Boot version and dependencies. No new language features are required by this change.

## Alternatives considered

- Retain Java 17 output while building on JDK 21: useful for Java 17 deployments, but none is
  required here and the user explicitly selected Java 21.

## Consequences

The application now requires Java 21 to run. Development needs the JDK, including compiler
tools and release metadata; a Java 21 runtime alone is insufficient. Changing the target does
not repair an incomplete JDK installation. Revisit only if deployment requirements change.
